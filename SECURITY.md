# Sicherheit / Security

## Deutsch

Eine Sicherheitslücke in Kante bitte **nicht** als öffentliches Issue melden, sondern privat:
[Lücke melden](https://github.com/vanozoda/kante-release/security/advisories/new) (GitHub → Security → „Report a vulnerability“).

Hilfreich sind die Version (Hauptmenü → „Nach Updates suchen …“), die Windows-Version, die Schritte zum Nachstellen und was dabei passiert. Gemeldet wird nur hier; Lücken in der WebView2-Engine selbst gehen an Microsoft.

Gemeint ist immer die neueste Version. Kante aktualisiert sich selbst; jedes Update ist signiert.

## English

Please do **not** report a security vulnerability in Kante as a public issue. Report it privately:
[report a vulnerability](https://github.com/vanozoda/kante-release/security/advisories/new) (GitHub → Security → "Report a vulnerability").

Please include the version (main menu → "Check for updates …"), your Windows version, the steps to reproduce and what happens. Vulnerabilities in the WebView2 engine itself go to Microsoft.

Only the latest version is supported. Kante updates itself; every update is signed.
